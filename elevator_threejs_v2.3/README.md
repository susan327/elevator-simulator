# Elevator Design Simulator v2.3

可変階数・可変停止階・3D実機ボタン対応版です。

## 主な追加
- 建物全階と停止階を分離する FloorServiceConfig
- 全階停止／1F＋10F以上／10階刻みシャトル／高層ゾーン
- `1,10-20,30,40` 形式のカスタム停止階
- 停止階だけホール呼びボタン・かご内階ボタンを生成
- 停止階数に応じて操作盤を2〜5列で自動配置
- Three.js Raycasterによる3Dボタンクリック
- 3Dボタン、右側GUI、運行キュー、ランプを同期
- 通過階では呼出不可、かごボタンも生成しない
- 40階建てや高層シャトル運転へ対応する土台

## 操作
`index.html`を開きます。Three.jsはCDNから読み込むためネット接続が必要です。
設計タブで階数と停止階パターンを変更すると自動再生成されます。
