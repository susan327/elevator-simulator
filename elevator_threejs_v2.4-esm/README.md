# Elevator Design Simulator v2.4

可変階数・可変停止階・3D実機ボタンに、方向優先運行・着床制御・自動閉扉を追加した運行ロジック改善版です。

## 主な追加
- 着床開始距離・着床速度を実際の運動曲線へ反映
- 進行方向を優先する呼びキュー
- 到着後4.5秒のドア保持と自動閉扉
- 開ボタンによる再開扉・保持時間延長
- カスタム停止階の厳密な入力エラー表示
- 建物全階と停止階を分離する FloorServiceConfig
- 全階停止／1F＋10F以上／10階刻みシャトル／高層ゾーン
- `1,10-20,30,40` 形式のカスタム停止階
- 停止階だけホール呼びボタン・かご内階ボタンを生成
- 停止階数に応じて操作盤を2〜5列で自動配置
- Three.js Raycasterによる3Dボタンクリック
- 3Dボタン、右側GUI、運行キュー、ランプを同期
- 通過階では呼出不可、かごボタンも生成しない
- 40階建てや高層シャトル運転へ対応する土台

## 開発環境

Three.jsはES Modulesとしてnpm管理し、Viteで開発・ビルドします。
Node.js `20.19.0`以上、または`22.12.0`以上が必要です。

使用バージョン：

- Three.js `0.160.1`
- Vite `8.2.2`

```powershell
npm install
npm run dev
```

起動後、ターミナルに表示されたローカルURLをブラウザで開きます。
設計タブで階数と停止階パターンを変更すると自動再生成されます。

## 公開用ビルド

```powershell
npm run build
```

生成物はプロジェクト直下の`app/`へ出力されます。
Three.js本体とアプリコードは別チャンクへ分割され、ブラウザキャッシュを再利用しやすい構成です。
